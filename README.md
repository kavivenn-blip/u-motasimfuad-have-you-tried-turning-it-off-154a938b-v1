One funny line a hopeless tech support agent gives a desperate customer: the agent turns the computer off and on again, and now the computer is asking *him* for tech support — so he puts them both on hold with each other.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (UTF-8, 147 characters, no trailing newline). It is deterministic, uses no network, and has no dependencies outside this repository.
